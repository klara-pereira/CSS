Seletores CSS 🌷


1. Seletor de Atributo

Seleciona elementos HTML com base em seus atributos.

input[required] {
    color: pink;
}

2. Seletor Descendente

Seleciona elementos que estão dentro de outros elementos..

div p {
    color: pink;
}

3. Seletor Filho Direto

Seleciona apenas os elementos que são filhos diretos de outro elemento.

div > p {
    color: pink;
}

4. Seletor Adjacente Direto

Seleciona o elemento que vem imediatamente depois de outro..

h2 + p {
    color: pink;
}

5. Seletor de Irmãos Gerais

Seleciona todos os elementos especificados que vêm depois de outro, no mesmo nível.

h2 ~ p {
    color: pink;
}

6. Seletor de Pseudoclasse

Aplica estilos a um elemento conforme seu estado ou posição.

a:hover {
    color: red;
}

7. Seletor de Pseudoelemento

Estiliza uma parte específica de um elemento, como a primeira letra de um texto.

p::first-line {
    color: pink;
}
